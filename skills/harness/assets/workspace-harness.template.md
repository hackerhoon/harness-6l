**센서 커버리지 (무인 운영의 선행 조건 — 전부 예여야 한다)**
- [ ] 인간 검사 없이 에이전트가 자기 출력을 검사할 수 있다
- [ ] 모든 중요 출력에 계산적 센서가 최소 1개 있다
- [ ] 센서 결과가 추세 분석용으로 기록된다
- [ ] 에이전트 동작이 변해도 센서는 안정적이다

- [ ] 어떤 작업도 예산을 초과하지 않음
- [ ] 에이전트가 최소 1회 올바르게 에스컬레이션함
