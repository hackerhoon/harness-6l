- [ ] 인간 검사 없이 에이전트가 자기 출력을 검사할 수 있다
- [ ] 모든 중요 출력에 계산적 센서가 최소 1개 있다

- [ ] 에이전트 동작이 변해도 센서는 안정적이다
- [ ] 어떤 센서도 건드리지 않고 조용한 회귀가 사용자에게 도달할 수 **없다**

**무인 운영 승격 게이트 (실사용이 채운다 — 팀 생성을 막는 게이트가 아니다)**

- [ ] **비상 정지 경로가 있고, 정지 시 상태가 보존된다**
- [ ] **무인 실행 3회 연속 성공**
